ภาพรวมสถาปัตยกรรม

Face Core เป็น hub กลาง — enroll, identify, verify, GPU queue, pgvector (512-d InsightFace buffalo_l). DPU เป็น BFF — คง URL เดิม (/face/*, kiosk WS) แต่ delegate vision ไป Face Core ผ่าน Docker network face-net. Check-in, GPS, HR ยังอยู่ที่ DPU

Standalone DPU ไม่มี Face Core: ใช้ POSTGRES_PORT=5432, HTTP_PORT=80

ติดตั้ง stack

1. เตรียม env

# face-core
cp .env.example .env   # POSTGRES_PORT=5435, REDIS_PORT=6380, HTTP_PORT=8081

# dpu-project
cp .env.example .env   # POSTGRES_PORT=5434, HTTP_PORT=8880

2. สร้าง network (ครั้งเดียว)

docker network create face-net

3. Terminal 1 — Face Core (CPU + Redis scale)

cd face-core
docker compose -f docker-compose.yml -f docker-compose.cpu.yml -f docker-compose.scale.yml up -d --build

4. Terminal 2 — DPU BFF

cd dpu-project
docker compose -f docker-compose.yml -f docker-compose.cpu.yml -f docker-compose.face-core.yml up -d --build

5. ตรวจสอบเร็ว

curl -s http://localhost:8081/v1/health
curl -s http://localhost:8880/docs

รายการตรวจ BFF smoke

  • GET / — โหมด Face Core BFF
  • GET /face/queue-stats — proxy ไป Face Core
  • POST add-face → faceEncodingId
  • POST identify company A — match ถูกต้อง
  • POST identify company B — reject (isolation)
  • POST check-in-walkby + GPS
  • GET kiosk-attendance roster
  • POST verify + GET encodings

แก้ปัญหาที่พบบ่อย

อาการสาเหตุแก้
bind: 5435 already allocated พอร์ต Postgres ชน Face Core 5435, DPU 5434 ใน .env; ลบ shell env override
dpu-api ไม่ resolve face-core-api ไม่ได้ join face-net ใช้ docker-compose.scale.yml + docker-compose.face-core.yml
identify ไม่ match ยังไม่ enroll หรือ company ผิด enroll ผ่าน Admin หรือ smoke add-face ก่อน
queue.backend=memory ไม่ได้รัน scale overlay เพิ่ม -f docker-compose.scale.yml
เปลี่ยน code แล้วไม่มีผล image เก่า docker compose … up -d --build face-api (หรือ api)
