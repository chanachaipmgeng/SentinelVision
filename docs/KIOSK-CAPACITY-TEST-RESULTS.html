1.1 สองเกณฑ์คุณภาพที่ใช้ตัดสิน

ใช้คู่กันเสมอ — Target = คุณภาพที่สัญญา · Acceptable = เพดานที่ยอมรับได้เมื่อต้องการจอเพิ่ม

Target คุณภาพหลัก

p95 ≤ 550 ms
  • ความรู้สึก: ตอบเร็ว ลื่น
  • drop ≤ 5%
  • ใช้เป็น SLA / สัญญาติดตั้งสาขา
  • rush ×3 gated ≈ 20–24 จอ
  • rush ×1 gated ≈ 40 จอ

Acceptable ยอมรับได้

p95 ≤ 1,000 ms
  • ความรู้สึก: ใช้งานได้ อาจหน่วงเล็กน้อย
  • drop ≤ 5%
  • ใช้หาเพดานจอสูงสุดที่ยอมได้
  • rush ×3 gated ≈ 32 จอ
  • rush ×1 gated ≈ 40 จอ (48 ไม่ผ่าน)
คำถามผู้บริหาร ตอบด้วย Target (550) ตอบด้วย Acceptable (1s)

ช่วงเช้า identify @24–32? ผ่านทั้งสองเกณฑ์ (p95 ~210–380 ms)

เมตริกตัดสินเพดาน rush: worst(detect p95, identify p95) · รายละเอียดรอบวัด §เพดานจอ

9.1 Chain Store / Edge crop identify

แนวสาขาเยอะ · ตรวจจับที่ Edge แล้วส่งเข้า API กลางด้วย preCropped=true · วัด A/B เทียบ identify เต็มเฟรม · เกณฑ์ Target 550 / Acceptable 1s

RPS สูงสุดในสเต็ปที่ยังผ่านเกณฑ์ Acceptable (p95 ≤ 1s · error ≤ 5%)

ประมาณการกล้องติดตั้ง = RPS × ช่วงยิงเฉลี่ยต่อกล้อง (สมมติ 1 รูป/30 วิ)
